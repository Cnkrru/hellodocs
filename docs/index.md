# hello

基于 Vue 3 + Vite 的静态文档站生成器：`docs/` 目录即站点，编译期直出静态 HTML，运行时只保留必要的交互。

```stat
100% | 编译期渲染
3 | CLI 命令
24 | 写作组件
```

## 开始使用

```steps
安装 | npm i -D hellodocs
写内容 | 在 docs/ 下新建 Markdown，目录层级即侧栏分组
本地预览 | npx hd dev，热更新实时生效
产出静态站 | npx hd build，dist/ 即为可部署产物
```

