## 折叠块 details

```details
为什么组件要走编译期实现？
编译期直出纯 HTML 后，浏览器拿到的就是成品结构，
不需要等待 JS 下载、解析、执行，首屏更快；
同时对搜索引擎和无 JS 环境更友好。
```

## 简易流程 flow

```flow
Markdown 源文件 | docs/ 目录
编译脚本 parseArticle | md → HTML + 元数据
vite-ssg 预渲染 | 每页生成独立 HTML
静态托管 | dist/ 直接伺服
```

## 定义块 define

```define
预渲染 | 构建期把每个路由渲染成完整 HTML，浏览器直接拿到成品
Hydration | 预渲染产物中残留的少量 JS，用于激活搜索等交互功能
编译期高亮 | 代码着色在构建时完成，运行时零开销
```
